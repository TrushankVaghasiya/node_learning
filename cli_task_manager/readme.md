# CLI Task Manager

this is a small cli task mannger where you can add task , mark task as comleted , view all task and remove task. This project was intended to get me introduce to the node js this is my first node project in my learnong journey.

# Usage

- **Add Task :** node index.js add --decription " task to add "
- **View all the task :** node index.js list
- **Mark Task Complete :** node index.js completed --id [task id]
- **Remove Task :** node index.js remove --id [task id]
