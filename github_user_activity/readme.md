# Git Hub Account Activity Lookup

This is the cli tool where you can look for the activity of any github username you want. this is the second project in my node learning journey.

# Usage

- **look :** node index.js look --username "[git hub username]"

# Concepts Learned

- **fetch requests :** how are fetch requests made to a specific url what is the return value of the fetch request , importance of async , await , then
- **solidifying yargs :** this also helped me to solidify the yargs framework to build own commands for cli
